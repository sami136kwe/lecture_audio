# lecture_audio
Application web locale qui lit des PDF à voix haute avec des voix naturelles en français et en anglais (Kokoro, Edge TTS, XTTS). Analyse la mise en page des PDF LaTeX (colonnes, en-têtes, pieds de page), lecture par paragraphe ou zone sélectionnée, notes et repli sur la voix du navigateur. Pensée pour l'étude.
